Pre-requisite 
This a python program that compresses the pdf documents below 2MB in a folder
All un-compressed pdf files are placed in a folder say c:\downloads\docs
In the same folder all compressed files will be stored
The program does not compress pdf files whose size is below 2MB
Change the folder path where PDF docs are located like c:\downloads\docs
Install gswin64c.exe   a ghost script application on the local system (this actually compresses the files)
Give the path of ghost script in the program like "c:\program Files\gs\gswin64c.exe"

Execution
Copy the script from Git hub to local system
Open the file in VSCODE or Jupyter or use command prompt or any other platform where python runs
now run the code 
you will get all compressed file in the same folder where the uncompressed files are present
